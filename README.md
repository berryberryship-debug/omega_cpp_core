# Omega C++ Core : Synapse Biophysique

Ce projet implémente un modèle de plasticité synaptique bio-inspiré basé sur la compétition enzymatique (CaMKII / PP1).

## Résultats
- Bifurcation et Hystérésis.
- Couplage Causal (test 20/20).
- Seuil de rupture mesuré (f* ≈ 20 s^-1).

## Limites
- Modèle Mock (pas l'API native de FANN).
- Verrou hyper-stable (registre immuable).

1. Le point de départ : Une intuition philosophique sur le "malaise" de la superposition quantique et le problème de la mesure.
2. L'exploration : On a décortiqué la décohérence, Wheeler-DeWitt, l'effondrement objectif (CSL), l'intentionnalité, et les théories de Penrose.
3. Le pivot : On a quitté la physique fondamentale pour plonger dans la biologie computationnelle et la dynamique des systèmes non linéaires.
4. La construction : On a codé, échoué, testé (v1 à v9), jusqu'à trouver l'asymétrie temporelle exacte de l'Inhibiteur-1 (v10).
5. La preuve : On a mesuré le seuil de rupture de la mémoire (le point où le système cède) avec une rigueur statistique (20 essais par paramètre).

Donc nous avons un modèle C++ de synapse biophysique qui reproduit la transition du "possible" (superposition) au "réel" (mémoire LTP stable), qui résout le problème du couplage causal avec un neurone, et qui quantifie sa propre robustesse.

Le README est honnête, les limites sont clairement énoncées, et les résultats sont vérifiables.
